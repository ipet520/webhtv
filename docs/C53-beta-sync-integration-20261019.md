## 本地结构与调用链证据

- Exo EOF 当前链路：MediaSourceFactory 创建外部代理 DataSource → HttpEofRecoveryDataSource 在未读 Range 位置重试 → ExoForegroundEofSignal 捕获真实 foreground Inputs → AutoPreloadPolicy 计算暂停原因 → PreCache.effectiveAutoDecision 决定是否硬停。现有本地 EOF 连续重试最多三次，但没有退避/角色信号；目标补丁只影响这条已有链路。目标 Media3 PriorityTaskManager 仅在工作任务调用 proceed 时仲裁，不能自动保证前台读取之间 preload 保持 idle；故需要显式让位信号。退出/关闭回调与退避睡眠同时发生时不得重开上游。
- 播放结果链路：SiteViewModel/详情取流 → VideoActivity.setPlayer 或 TmdbDetailActivity.playInline → generation/ownership 守卫 → UI loading flags。保留本地请求 generation、TMDB 并发控制、详情和播放 handoff 语义。
- PlaybackActivity.stopPlayback 本地已有 owner shutdown 逻辑与非 owner 异步停止路线；目标 non-owner suspend 不可直接套用，因为本地 PlaybackService.suspend 会停止并清共享播放器/notification。仅补中央 start-after-exit guard。
- HLS 去广告三路径：MpvHlsProxy、ExoHlsAdblockDataSource、M3u8 → HlsAdblockNotice.message/durationText。只变更成功提示文案与计时格式，不改变广告识别、跳过区间、时间轴或配置。
- Android 7 兼容：minSdk=24；Matcher StringBuilder overload、Process.isAlive、View.setImportantForAutofill 分别具有更高平台 API 门槛。安全改为官方 API 1/compat 等价调用，保持算法和对话框行为。
- IJK 诊断由 PlayerOsdController 的 analytics 数据分派控制；MPV 已有专属统计。本次只补 IJK 来源，不改其它引擎计数。
- NO_CONFIG 使用现有 ProgressLayout/state events，不引入上游完整 error-page 状态机；TV/Mobile 复用空态 overlay，并提供通向既有 VOD 配置管理器的动作。只在配置源实际可用且首页收到 HOME refresh 时收起 no-config overlay。当前目标最后的 Callback 宿主 noConfig 修复必须与 0f1dc0c615b3ac04e8c22af9f16c75286e3e648a 一起纳入。

## External and platform evidence

Reviewed 2026-10-19:
- Android Matcher API: https://developer.android.com/reference/java/util/regex/Matcher. StringBuffer appendReplacement/appendTail overloads exist on API 1; StringBuilder overloads were added in API 34. This matters because the App supports minSdk 24.
- Android Process API: https://developer.android.com/reference/java/lang/Process. isAlive is API 26; exitValue plus IllegalThreadStateException is API 1-compatible.
- Android View API: https://developer.android.com/reference/android/view/View. setImportantForAutofill was added in API 26; use androidx.core.view.ViewCompat.
- Media3 priority: https://developer.android.com/reference/androidx/media3/common/PriorityTaskManager and https://developer.android.com/reference/androidx/media3/datasource/PriorityDataSource. Priority only gates tasks at the cooperative proceed points.
- Media3 preload behavior: https://developer.android.com/media/media3/exoplayer/preloading-media/preloadmanager/concepts and https://developer.android.com/media/media3/exoplayer/preloading-media/preloadmanager/manage-play. Supports controlled preload but does not validate this local proxy’s 15-second value.
- Android Direct Boot: https://developer.android.com/privacy-and-security/direct-boot. Confirms credential-encrypted versus device-encrypted startup boundaries; not sufficient to safely migrate this App’s worker initialization.
- Upstream E-SP10/C82 source and tests were inspected at the fixed target. Upstream reports its own correlated EOF/preload observations (176/177 recoveries during active preload, 15-second suppression window with no observed EOFs); these are upstream observations, not local device evidence. The target’s later C82 review fixed a policy-classification omission. Current App’s longer retry backoff and device impact remain to be validated locally.

### 已确认的 Lab selector 状态优先级回归

- 来源：实验室候选 `978bfa1e2644638430f6241d7cfd29b06a87dbc8` 的最终树把运行按钮 `state_pressed` 放在 `state_enabled=false` 之前；本地历史 `LOCAL_BASE=80766ab3e3455968aa64ee8489bafcdec6731d91` 原来是 disabled 优先。候选加入可见聚焦样式时改错了 selector 首匹配顺序。
- 生产路径：`LabCommandSheet.updateRunState()` 会在站点未安装或命令不支持时执行 `sheetBtnRun.setEnabled(false)`。Android selector 从上向下匹配，因此同时给出 `-state_enabled` 与 `state_pressed` 时旧同步结果错误选中 pressed 颜色。Leanback `ThemeGlobalSemanticContractTest.disabledStateWinsOverActiveStateAcrossSharedSelectors` 第 274 行原有断言在未改变的情况下复现失败：期望 `white_20`（872415231），实际得到按下态蓝色（-870213901）。同步前的 `80766...` selector 顺序则让 disabled 项先命中。
- 本地/上游比较：上游最终树沿用 pressed 在前的顺序，会保留 enabled 控件的 pressed 反馈，但无法满足本地 disabled 语义；本地修正只将 disabled 提到 pressed 之前，focused 项仍在两者之后。对 enabled 控件，pressed/focused 样式不变；禁用控件始终显示 disabled 样式。相同优先级也应用于点击动作 `shape_lab_click_btn`，其禁用态未来可用且不会依赖 View 一定抑制 pressed 状态。
- 修复：保留原 run selector 断言并新增同样的 click selector 断言，未放宽或删除任何断言。没有修改焦点边框颜色、图标、按钮尺寸、导航关系或主题 Token。
- 验证：Leanback `ThemeGlobalSemanticContractTest` 13/13；`com.fongmi.android.tv.lab.*` 31/31，全部通过。静态/自动化结果不代表遥控器真机操作已通过；仍需在 TV 上检查运行按钮被禁用时的视觉、D-pad 进入/离开命令卡片及命令详情焦点返回。
